# Misión Emprende - Proyecto Full-Stack

Este es el repositorio principal del proyecto "Misión Emprende". Contiene el backend, el frontend y los scripts de la base de datos.

## Estructura del Proyecto

- **/backend**: Contiene el servidor construido con Django y Django Rest Framework.
- **/frontend**: Contiene la aplicación de interfaz de usuario construida con React.
- **/basedatos**: Contiene los scripts SQL para crear y poblar la base de datos PostgreSQL.

## Cómo Empezar

Consulta la documentación dentro de cada carpeta para obtener instrucciones sobre cómo ejecutar el backend y el frontend o consultar por interno en grupo.
