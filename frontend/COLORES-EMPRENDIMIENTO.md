# Colores - Temática de Emprendimiento


## *Paleta de Colores Implementada**

### **Colores Principales:**
- **Azul Principal/Fondo**: `#2E5E8C` - Utilizado para headers, sidebar y elementos principales
- **Cyan**: `#00B8A9` - Botones principales y elementos activos  
- **Amarillo**: `#FDC328` - Elementos destacados y badges
- **Rosa**: `#E24872` - Botones de acción secundaria (logout, eliminación)
- **Naranja** (opcional): `#FF7B39` - Para futuros elementos especiales

### **Colores de Hover:**
- **Azul Hover**: `#254c72`
- **Cyan Hover**: `#00a396`
- **Amarillo Hover**: `#e6b023`
- **Rosa Hover**: `#d13963`
- **Naranja Hover**: `#e66d33`

##  **Archivos Modificados**

### **1. Configuración de Tailwind**
- **Archivo**: `frontend/tailwind.config.js`
- **Cambios**: Agregados los colores personalizados de la temática de emprendimiento

### **2. Módulo Profesor**
- **ProfessorLayout.jsx**: Header y sidebar actualizados con nuevos colores
- **HomeView.jsx**: 
  - Banner principal con gradiente azul-cyan
  - Tarjetas de estadísticas con colores temáticos
  - Botones de acción rápida con colores específicos
  - Tabla con header azul principal

### **3. Módulo Administrador**
- **AdminLayout.jsx**: Header actualizado con colores temáticos
- **SidebarAdmin.js**: Sidebar con fondo azul principal y elementos activos en cyan
